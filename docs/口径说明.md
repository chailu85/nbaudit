# 统计口径说明（桌面改版前）

> 本文件只记录当前源码的统计口径，不修改审核条目、评分判定、自动复核或页面文字。

## 1. “制度与档案”为什么会出现 0/1 与 0/2

在默认的空白单位画像下，当前现行基线评分集合只激活 `R-01`，因此审核总览按 `current.domestic` 统计时显示 **0/1**。分模块审核使用 `forwardScore.active` 作为当前条款列表；其中 `R-02` 属于前瞻依据，进入审核页但不进入现行基线总览，所以审核页当前条款集合显示 **0/2**。

这不是同一个集合的重复计算：

- **总览**：`score(criteria, answers, profile, false)`；`domestic` 只保留现行国内基线，并排除前瞻依据和补充项。
- **分模块审核**：`score(criteria, answers, profile, true)`；`active` 允许前瞻依据，审核页可以列出比总览更多的条款。
- 当前 `Assessment` 左侧模块统计还读取 `allCriteria`（`App.tsx` 中 `moduleStats`），因此该处若显示原始模块总数，可能与右侧当前条款数量再次不同；这是展示集合不同，不是评分逻辑改变。

对应源码：

| 位置 | 作用 |
|---|---|
| `client/src/lib/scoring.ts:71-78` | `active`、`domestic`、`counted` 的集合定义 |
| `client/src/App.tsx:38-40` | 总览评分与审核页评分的两个快照 |
| `client/src/App.tsx:195,198` | 总览按 `snapshot.domestic` 显示模块数量 |
| `client/src/App.tsx:226-230,283,285` | 审核页模块统计和当前条款列表 |
| `client/src/data/criteria.ts` 中 `R-01/R-02` | 制度与档案条款及其前瞻属性 |

## 2. “全部 132 项 / 当前计分 123 项”与报告“国内适用项目 123”

这三个数在**同一个默认空白画像、同一份当前档案**下的含义如下：

1. 总览“全部 132 项”：`current.domestic.length`。它是当前画像触发的全部现行国内适用条款，包含建议项以及尚未去重的旧父项。
2. 总览“当前计分 123 项”：`current.counted.length`。它从现行国内条款中排除有效“不适用”项，并去除已由 A04 原子控制替代的旧父项，只保留计分分母。
3. 报告“国内适用项目 123”：报告直接读取同一个 `current.counted.length`，所以在同一档案和同一画像下应与总览“当前计分”一致；它不是 132 的另一种展示，而是同一计分集合的报告字段。

对应源码：

| 位置 | 作用 |
|---|---|
| `client/src/App.tsx:195` | 总览显示 `snapshot.domestic.length` 和 `snapshot.counted.length` |
| `client/src/App.tsx` 的 `Report` 组件 | 报告统计块显示 `current.counted.length` |
| `client/src/lib/scoring.ts:74-78` | 国内适用集合、强制集合和去重计分分母 |
| `client/src/lib/scoring.ts:64` | A04 旧父项去重函数 `deDuplicateParents` |

本基线样例画像更广（重点单位、特殊风险和 A04 场景均打开），因此回归预期使用的是另一组可复现数字：总览国内适用 **221**、报告/计分分母 **180**。该差异来自画像和样例答案，不是页面计算不一致。

## 3. “依据库 261 个审核项目已建立追溯映射”

依据库的 261 是完整 `criteria` 审核条目目录的长度，不经过当前单位画像、前瞻开关、有效“不适用”或计分去重过滤。`App.tsx` 将完整 `criteria` 作为 `SourceLibrary.items` 传入；`SourceLibrary.tsx` 用 `items.length` 显示“个审核项目已建立追溯映射”。

因此三组数字的层级不同：

| 数字 | 集合 | 是否受画像/状态影响 |
|---:|---|---|
| 132 | 当前默认画像的现行国内适用集合 `current.domestic` | 是 |
| 123 | 当前默认画像的计分分母 `current.counted` | 是；排除有效“不适用”并去重 |
| 261 | 完整审核条目目录 `criteria` | 否；依据库目录总量 |

对应源码：

- `client/src/App.tsx:167`：向依据库传入完整 `criteria`。
- `client/src/components/SourceLibrary.tsx:45`：显示 `items.length`。
- `client/src/data/criteria.ts`：完整审核条目数据目录。
- `client/src/lib/scoring.ts:71-78`：当前画像下的评分集合和计分分母。
