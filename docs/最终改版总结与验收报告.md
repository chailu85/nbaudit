## 一、项目概述

本项目面向单位内部治安保卫合规审核场景，围绕 DB11/T 2552—2026《单位内部安全防范通用要求》全文建立审核工作台，并兼顾 2004 版《企业事业单位内部治安保卫条例》和修订征求意见稿的依据映射。系统采用本地优先模式，审核画像、答案、证据、整改和复核信息保存在用户浏览器本机，不上传审核材料。

本次改版的目标是：在**不改变任何业务数据、评分判定、自动复核、导入导出、本地保存和状态管理行为**的前提下，将现有界面统一为 Swiss / Internationalist（瑞士/国际主义）视觉体系，并完成桌面端多档响应式适配、键盘可操作性和跨页面条款定位收尾。

### 2.2 设计系统

- 字体使用 Inter、Noto Sans SC / Source Han Sans SC；数字使用等宽数字和 tabular numerals。
- 颜色以黑、白、灰为主，信号红仅用于“不符合”“高风险”“关键缺口”和错误提示。
- 间距、字号、边框、圆角和阴影统一从 `client/src/styles/tokens.css` 读取。
- 桌面尺寸使用 rem；桌面媒体规则未发现 px 字号或硬编码颜色。
- 保持无渐变、无阴影、无圆角、无彩色底色标签和无装饰性图标方块的视觉约束。

## 三、跨页面交互与可访问性

### 3.1 条款定位

总览、整改清单、依据与差异、审核报告中的可定位条款编号均可跳转至对应审核页。来源库仅在满足以下条件时渲染安全跳转：

1. 与审核项目属于同一标准来源；
2. 标准条款号精确匹配；
3. 当前条款适用；
4. 只有一个适用候选。

无精确映射、条款不适用或候选存在歧义时，编号保持统一的 12px 等宽灰色文本，不生成可能误导用户的链接。

### 3.2 键盘与焦点

- 全局保留 2px 黑色 `:focus-visible` 焦点描边。
- 分模块审核保留键盘切换条款和使用 `1/2/3/4` 选择判定的行为。
- 整改行保留鼠标点击以及 Enter / Space 键展开行为。
- 条款编号、按钮和表单控件均维持可访问的语义控制元素。
