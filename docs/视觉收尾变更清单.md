# 全站视觉收尾：变更清单

> **日期**：2026-10-04  
> **范围**：当前生产入口 `client/src/main.tsx` 所加载的 `App.tsx`、`SourceLibrary.tsx`、`index.css` 与 `styles/tokens.css`。

## 1. 本轮交互变化

| 页面 | 调整后的交互 | 数据影响 |
|---|---|---|
| 审核总览 | “需人工复核”中的既有审核条款编号维持可点击，并定位至所属模块和对应条目。 | 无；仅临时页面定位状态。 |
| 分模块审核 | 接收来自其他页面的条款定位；点击后清除页面内搜索筛选并显示对应的现有审核项。 | 无；不改答案、评分或复核。 |
| 整改清单 | 整改行中的审核条款编号可直接回到对应审核项；行本身保留展开编辑行为，并补齐键盘 Enter/Space 展开。 | 无；整改字段及关闭校验未改。 |
| 依据与差异 | 仅对**当前适用、且与审核条目存在同标准来源、精确标准条款号和唯一候选映射**的来源条款提供跳转；无精确映射、当前不适用或候选歧义的标准索引保持同样的12px等宽灰色编号，不伪造审核映射。 | 无；未新增或修改条款映射数据。 |
| 审核报告 | 缺口、不适用与整改明细中的既有审核条款编号可定位到对应审核项。 | 无；Word、Excel和打印内容未改。 |

## 2. 视觉和可访问性收尾

- `tokens.css` 增加 `--space-0` 与 `--font-mono`；当前生产页面的颜色、字号、间距、边框、圆角和阴影继续引用令牌。
- 去除运行页面中的彩色背景标签、卡片化依据摘要、图标方框和非语义信号红；红色仅保留在不符合、高风险、关键缺口或错误提示语义。
- 所有审核条目 ID 采用统一的 **12px、等宽数字、灰色** 样式；可定位的 ID 具有至少一个控制高度的点击面。
- 全局键盘焦点为 2px 黑色描边；整改行同时支持鼠标和键盘 Enter/Space 展开。
- 为长文本和窄屏容器增加断词与最小宽度约束；375、768、1024、1440px 的已渲染框架检查未发现横向溢出或被截断的主内容。

## 3. 明确未改的功能

- 未改审核条目、依据数据、适用性、评分、判定、自动人工复核、整改关闭规则、模块统计或任何数值口径。
- 未改 JSON/Word/Excel 的数据结构、导入兼容、导出字段、`localStorage` 保存、自动保存或状态迁移。
- 未增加、删除任何业务字段或页面功能；条款定位只使用未持久化的当前页面状态。
